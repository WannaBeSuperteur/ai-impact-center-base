## 1. 개요

[AI Impact Center](https://github.com/WannaBeSuperteur/ai-impact-center/tree/main) 개발을 위한 베이스라인 코드

### 1-1. 구성 요소

**1. 모델 학습 및 에이전트 파이프라인**

* 딥러닝 모델 학습 파이프라인
  * Vision 모델
  * 데이터 수집 → 전처리 → 모델 학습 → 테스트 → 모델 저장
  * 모델 로딩 → inference
  * 학습 진행 상황 및 테스트 결과 테이블화, 그래프 시각화 등

* LLM 학습 파이프라인
  * LLM 기본 학습 파이프라인 (모델 다운로드 → 모델 학습 → 모델 저장)
  * 정량 평가 (BLEU, ROUGE, LLM-as-a-judge 등)

* AI 에이전트 파이프라인
  * 도구 호출 (Python 함수 실행) 등 포함
  * HuggingFace 모델을 LLM으로 사용하는 에이전트
  * smolagents 사용 예정

* 기타 모델 학습 파이프라인
  * 텍스트 임베딩 모델 (확률 추론, 유사도 비교)

**2. 모델 연계 파이프라인 (배포 등)**

* 다음 5가지 기술 도입
  * FastAPI, ONNX, MLflow, vLLM, Airflow 등
    * 단, Airflow는 현재가 아닌 차기 버전 도입 예정   
  * 프로젝트 조건 고려할 때, 위 기술보다 적절한 기술이 존재하는 경우 해당 기술 사용 가능
