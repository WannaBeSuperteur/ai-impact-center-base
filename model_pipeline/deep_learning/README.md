## 1. 개요

* 딥러닝 모델 학습 파이프라인
* 모델 종류
  * Vision 이미지 분류 모델
  * 임의의 딥러닝 모델

## 2. Vision 이미지 분류 모델

* 입력
  * 학습 데이터 경로
  * 학습 데이터 카테고리 (디렉토리 이름, 별도 카테고리명 추출 함수)
  * Train/Valid/Test 구분 비율
  * 학습할 모델 이름 (`timm` 기반) 또는 학습할 모델이 저장된 경로
  * 학습 옵션 (early stopping, learning rate 등)
  * 학습 완료된 이미지 분류 모델의 저장 경로

* 출력
  * 학습 완료된 이미지 분류 모델
  * 학습 완료된 모델의 테스트 결과 (성능지표 등)

* 추가 기능
  * 모델 inference 로직
  * 모델 성능 평가 결과 markdown 자동 추출 로직
  * (v1.1 예정) 오답을 한 이미지에 대한 markdown 자동 추출 로직
  * (v1.1 예정) 오답을 한 이미지에 대한 설명 가능한 AI (XAI) 알고리즘 기반 설명 로직 (논문 탐색 필요)

## 3. 임의의 딥러닝 모델

* 입력
  * 학습 데이터셋 (데이터셋 class)
  * Train/Valid/Test 구분 비율
  * 학습할 모델 자체
  * 학습 옵션 (early stopping, learning rate 등)
  * 학습 완료된 모델의 저장 경로

* 출력
  * 학습 완료된 모델
  * 학습 완료된 모델의 테스트 결과 (성능지표 등)

* 추가 기능
  * 모델 inference 로직
  * 모델 성능 평가 결과 markdown 자동 추출 로직
  * (v1.1 예정) 오답을 한 데이터에 대한 markdown 자동 추출 로직
